# Java Functional Programming Demo

## Project Title
Java Functional Programming Using Lambda Expressions and Stream API

## Objective
The objective of this project is to demonstrate the basic concepts of Functional Programming in Java using Lambda Expressions and the Stream API.

## Description
This program creates a list of integers and performs functional operations on the data. It uses a lambda expression to display the elements and the Stream API to filter numbers greater than 20 and calculate their sum.

## Features
- Demonstrates Lambda Expressions
- Uses Java Stream API
- Filters data using functional programming techniques
- Calculates the sum of filtered elements
- Simple and beginner-friendly implementation

## Technologies Used
- Java 8 or Higher
- VS Code / Eclipse IDE

## Program Flow
1. Create a list of integers.
2. Display all elements using a lambda expression.
3. Filter numbers greater than 20 using Stream API.
4. Calculate and display the sum of filtered numbers.
